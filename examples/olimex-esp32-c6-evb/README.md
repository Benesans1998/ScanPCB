# Olimex ESP32-C6-EVB

Board ID: `OLIMEX-ESP32-C6-EVB`  
Manufacturer: Olimex Ltd  
Documented hardware revision: `A`

This ScanPCB example describes the real open-source hardware board ESP32-C6-EVB using links published by Olimex. It intentionally does not mirror the upstream manuals, schematics, KiCad project, software examples or product photographs.

## Verified facts used by this example

- ESP32-C6-WROOM-1-N4 module with 4 MB flash;
- Wi-Fi 6, Bluetooth 5 LE and IEEE 802.15.4 connectivity;
- USB-C power, programming and JTAG;
- four 10 A / 240 VAC relays;
- four opto-isolated 5 to 30 VDC inputs;
- two UEXT connectors and GPIO expansion;
- 100 x 70 mm board dimensions;
- OSHWA certification UID `BG000116`;
- hardware revision A in the official repository.

The authoritative source is the [Olimex product page](https://www.olimex.com/Products/IoT/ESP32-C6/ESP32-C6-EVB/open-source-hardware). Repository links and licenses are recorded in [scanpcb.yaml](scanpcb.yaml).

## Copyright and reuse approach

The ScanPCB metadata and diagnostic organization in this folder are original project files. The Olimex repository README declares:

- hardware: CERN OHL v1.2;
- software: GPL-3.0;
- documentation: CC BY-SA 3.0.

The OSHWA certification record instead lists CERN-OHL-S-2.0, GPL-3.0-or-later and CC-BY-SA-4.0. ScanPCB therefore does not normalize this discrepancy: verify the license attached to the exact upstream artifact before redistribution.

The product photograph is not copied into ScanPCB because the product-page image license is not separately stated. The web demo references the image at its official Olimex URL and links back to the product page. This keeps attribution visible and avoids redistributing an uncertain asset.
