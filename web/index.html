ScanPCB principle 001

A durable link

From physical hardware to maintainable knowledge.

The QR is only the entry point. The valuable part is a repository that remains portable, reviewable and complete.

The repository is the source of truth.

YAML describes identity and revisions. Markdown carries repair knowledge. CSV keeps the BOM portable. Native design files stay with the board.

  • Readable without a proprietary service
  • Versioned and reviewed with Git
  • Exportable as ordinary files
  • Ready for community contributions

Open formats

Files first

YAML, Markdown, CSV, SVG and native EDA sources remain useful outside ScanPCB.

Traceability

Every revision stays visible

Schematic, PCB, firmware and known issues can follow the hardware they actually describe.

Repair knowledge

Measurements have context

Test points record conditions, instruments, units, tolerances and expected signal behavior.

Collaboration

Git is enough to begin

Issues and pull requests already support proposals, review, corrections and history.
